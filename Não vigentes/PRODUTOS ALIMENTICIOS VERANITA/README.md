# Veranita Produtos Alimenticios

Site institucional desenvolvido pela **ADS**.

Paginas: inicio, nossa historia, produtos (com busca e filtro por categoria),
ficha de cada produto, receitas e contato.

O codigo desta pasta foi remontado a partir do site publicado — leia o
[NOTA-FONTE.md](NOTA-FONTE.md) antes de mexer.

## Tecnologias

- React + Vite + TypeScript
- Tailwind CSS
- React Router (varias paginas)
- Framer Motion (animacoes)
- Supabase (grava os formularios de contato)

## Como rodar localmente

```bash
npm install
npm run dev
```

Build de producao:

```bash
npm run build
```
