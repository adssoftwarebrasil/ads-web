# Posto de Molas 3 Bandeiras

Site institucional do Posto de Molas 3 Bandeiras, criado com React, Vite e JavaScript.

## Requisitos

- Node.js 20 ou superior
- npm

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```

A versão pronta será criada na pasta `dist`.

Para conferir a versão de produção localmente:

```bash
npm run preview
```

## Publicação manual na Vercel

- Framework Preset: Vite
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

O projeto não usa rotas no navegador e não precisa de `vercel.json`.

## Variáveis de ambiente

Nenhuma variável de ambiente é necessária.
