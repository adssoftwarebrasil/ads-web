# JR Baterias

Site institucional desenvolvido pela **ADS**.

Publicado em: https://jr-baterias.netlify.app/

## Tecnologias
- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Como rodar localmente
```bash
npm install
npm run dev
```

Build de producao:
```bash
npm run build
```

## Estrutura
- `src/config/site.ts` — todo o conteudo do site (textos, contatos, servicos, FAQ, SEO)
- `src/components/` — secoes da pagina
- `public/images/` — imagens (webp)
